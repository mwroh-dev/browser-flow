# Phase 86 — heal-agent skill + heal-apply + (cleanup→heal→re-run) orchestration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]`. **Real-Chrome e2e (86.5) MUST use a hard `{timeout}` + zombie-kill + `rm -f profiles/*/Singleton* profiles/*/RunningChromeVersion`.** Run single test files with `node --test --import=./tests/_setup.mjs <file>` (direct `node --test` gives false isolation-guard failures).

**Goal:** Close the 빵틀 heal loop's model half: when a run drift-holds and emits a `heal-request.json` (Phase 85), an **internal heal sub-agent** (no external LLM) reasons over it to produce a `heal-result.json` (healed Phase-81 locators OR `partial-incomplete`); `bf heal --apply` deterministically applies the healed locators to the workflow (self-heal cache), then runs cleanup (Phase 84) + a full re-run.

**Architecture:** Three deterministic, LLM-free pieces — a `HealResult` schema, a pure `applyHeal(workflow, healResult)`, and a `bf heal` command that wires read-request → apply → regenerate → cleanup → re-run — plus one model piece, a `heal-agent` SKILL.md the orchestrator dispatches via the Task tool. The model NEVER runs at replay time and NEVER via an external API/CLI; it is strictly an in-system sub-agent that writes `heal-result.json`. The heal is **bounded**: the sub-agent returns healed-locators OR partial-incomplete, and `bf heal` does exactly one re-run (no runtime retry loop).

**Tech Stack:** Node ESM `.mjs`, Zod, `node --test`, TS strict checkJs. No new deps, no LLM in code. Keep `npm run check` GREEN.

**Spec:** `docs/superpowers/specs/2026-05-21-mold-heal-loop-design.md` §4 (heal-agent), §5 (orchestration), §6 (decomposition). Parent north-star: `2026-05-21-mold-self-healing-automation-design.md`.

## Decisions locked
1. **Orchestration surface = `bf heal` CLI command** (user decision). Deterministic parts only; the model stays a separate internal sub-agent. `bf heal --run-id X` prints the heal-request (sub-agent input). `bf heal --run-id X --apply <heal-result.json>` applies + cleanup + re-run.
2. **Model invocation = internal sub-agent ONLY** (`heal-agent` SKILL.md, dispatched via Task/Agent — like variable-agent). No external LLM API, no `claude -p`, no `codex spawn`. Code is LLM-free; the skill reasons, the code applies. (Spec §2, user verbatim.)
3. **Bounded heal**: heal-result is `healed` (non-empty healedLocators) XOR `partial-incomplete` (reason). `bf heal --apply` does ONE re-run; if the re-run drift-holds again it returns the new held report — NO auto re-heal loop (avoids infinite digging).
4. **Self-heal cache = `step.locator` replacement** (the load-bearing field the resolver uses). Match by the OLD `structuralKey` (the disappeared key from heal-request). `mold.json` refresh is deferred — it is regenerated by `bf analyze`/compile and is diagnostic-only; updating the workflow's `step.locator` is what makes the next run deterministic. (Spec §9.3, scoped tight.)
5. **Resume = cleanup + full re-run** (spec §5). Not partial-from-journal. `partial-incomplete` → mark the held segment + compute Phase 83 `affectedByHold` cascade, return WITHOUT re-running.
6. **Synthetic-mode test** (spec §6): the e2e supplies a hand-written `heal-result.json` (standing in for the sub-agent) so the full loop is proven deterministically with no LLM.

```js
/**
 * Apply a heal-result to a workflow. Pure: returns a new workflow object;
 * the input is not mutated. Matches steps by the OLD locator.structuralKey
 * and replaces step.locator with the healed locator.
 * @param {{ steps: Array<Record<string, any>> }} workflow
 * @param {{ status: string, healedLocators?: Array<{match:{structuralKey:string}, locator:Record<string,any>}>, reason?: string }} healResult
 * @returns {{ workflow: any, applied: string[], unmatched: string[], status: string, reason?: string }}
 */
export function applyHeal(workflow, healResult) {
  if (healResult.status === "partial-incomplete") {
    return { workflow, applied: [], unmatched: [], status: "partial-incomplete", reason: healResult.reason };
  }
  const next = structuredClone(workflow);
  const applied = [];
  const unmatched = [];
  for (const entry of (healResult.healedLocators || [])) {
    const key = entry.match.structuralKey;
    const step = next.steps.find((s) => s && s.locator && s.locator.structuralKey === key);
    if (step) { step.locator = entry.locator; applied.push(key); }
    else { unmatched.push(key); }
  }
  return { workflow: next, applied, unmatched, status: "healed" };
}
```
