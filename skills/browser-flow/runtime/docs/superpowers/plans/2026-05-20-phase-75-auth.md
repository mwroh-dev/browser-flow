# Phase 75 — Auth Model (②) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]` checkboxes.

**Goal:** verify reaches the authenticated precondition without the agent ever seeing credentials: first verify = human types login (2FA by human) → authenticated **session** saved to OS keychain; repeat verify = runner reads the session from keychain and injects it into a fresh profile before replay. Password is never stored; only the session.

**Architecture:** New `keychain.mjs` (macOS `security` CLI, injectable exec → mockable, value never logged) + `session-state.mjs` (capture/inject cookies via raw CDP `Network.getCookies`/`setCookies`). `generate-runner.mjs runWorkflow` gains `sessionState` injection between session-create and navigate. `verify-run.mjs` gains `first`/`repeat` modes. Builds on Phase 73 (`preconditions` field), Phase 64 CDP client, `generate-runner.mjs:207/248` hooks.

**Tech Stack:** Node ESM `.mjs`, `node:child_process` (`execFileSync` for `security`), raw CDP (`Network.*`), Zod, `node --test` (`--import=./tests/_setup.mjs`), TS strict + checkJs (keep `npm run check` GREEN).

**Spec:** `docs/superpowers/specs/2026-05-20-human-in-loop-verify-design.md` §②.

**Agent-blind invariant (load-bearing):** the session value lives only in (1) the live Chrome profile, (2) the OS keychain. It must NEVER appear in `artifacts/`, `verification.json`, stdout, or any agent-visible output. Tests assert this explicitly.

import { execFileSync } from "node:child_process";

const ACCOUNT = "browser-flow";

/** @typedef {(file: string, args: string[]) => string} ExecFn */

/** @param {{ exec?: ExecFn }} [opts] */
function resolveExec(opts) {
  return opts?.exec ?? ((file, args) => execFileSync(file, args, { encoding: "utf8" }));
}

/**
 * Store a session value in the OS keychain (base64-encoded so the raw
 * secret is not a plaintext CLI arg). Value never returned in errors/logs.
 * @param {string} ref @param {string} value @param {{ exec?: ExecFn }} [opts]
 */
export function saveSession(ref, value, opts) {
  const exec = resolveExec(opts);
  const encoded = Buffer.from(value, "utf8").toString("base64");
  exec("security", ["add-generic-password", "-a", ACCOUNT, "-s", ref, "-w", encoded, "-U"]);
}

/**
 * Read a session value. Returns null if absent. Never logs the value.
 * @param {string} ref @param {{ exec?: ExecFn }} [opts] @returns {string | null}
 */
export function readSession(ref, opts) {
  const exec = resolveExec(opts);
  let out;
  try {
    out = exec("security", ["find-generic-password", "-a", ACCOUNT, "-s", ref, "-w"]);
  } catch {
    return null;
  }
  return Buffer.from(out.trim(), "base64").toString("utf8");
}

/** @param {string} ref @param {{ exec?: ExecFn }} [opts] */
export function deleteSession(ref, opts) {
  const exec = resolveExec(opts);
  try { exec("security", ["delete-generic-password", "-a", ACCOUNT, "-s", ref]); } catch { /* absent */ }
}
```

/**
 * @typedef {{ cookies: Array<Record<string, unknown>> }} SessionState
 */

/**
 * Capture the authenticated session (cookies) from a live CDP session.
 * @param {{ send: Function }} client @param {string} sessionId @returns {Promise<SessionState>}
 */
export async function captureSessionState(client, sessionId) {
  await client.send("Network.enable", {}, sessionId).catch(() => {});
  const result = /** @type {any} */ (await client.send("Network.getCookies", {}, sessionId));
  return { cookies: Array.isArray(result?.cookies) ? result.cookies : [] };
}

/**
 * Inject a saved session (cookies) into a fresh CDP session before navigate.
 * @param {{ send: Function }} client @param {string} sessionId @param {SessionState} state
 */
export async function injectSessionState(client, sessionId, state) {
  const cookies = Array.isArray(state?.cookies) ? state.cookies : [];
  if (cookies.length === 0) return;
  await client.send("Network.enable", {}, sessionId).catch(() => {});
  await client.send("Network.setCookies", { cookies }, sessionId);
}
```
